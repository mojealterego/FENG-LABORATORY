# FENG-LABORATORY

Repozytorium projektu **Thermo-IoT**: koncepcji bezbateryjnego węzła telemetrycznego zasilanego odzyskiem energii z gradientu temperatury na instalacjach ciepłowniczych.

> **Status:** badania koncepcyjne / pre-prototyp. Brak potwierdzonego TRL 4, demonstratora sprzętowego, zgłoszenia patentowego, zweryfikowanej przewagi konkurencyjnej i gwarancji przyznania wsparcia.

## Zakres

- **Grant:** robocza dokumentacja aplikacyjna FENG 2.27 Laboratorium Innowatora; informacje formalne należy sprawdzić w aktualnym regulaminie wybranego operatora.
- **Inżynieria:** pomiary `ΔT`, model budżetu mocy TEG/PMIC/superkondensatora oraz cykl transmisji LPWAN.
- **Prototyp cyfrowy:** narzędzia offline do liczenia wykonalności energetycznej, scenariusze i testy.
- **Walidacja:** plan laboratoryjny, mapa ryzyk, kryteria GO/NO-GO i rejestr twierdzeń wymagających dowodów.

Wiodący pomysł: *najpierw obronić powtarzalny bilans mocy i warunki instalacyjne, dopiero następnie rozszerzyć funkcje o pomiar przepływu i modele predykcyjne*.

Poniższe pliki będą rozwijane w kolejnych commitach w gałęzi `main`.

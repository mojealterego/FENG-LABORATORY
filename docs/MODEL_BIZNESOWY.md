# Thermo-IoT — Business Model Canvas (hipotezy)

| Obszar | Założenie do walidacji |
|---|---|
| Klient | przedsiębiorstwa ciepłownicze i zakładowe utrzymanie ruchu |
| Wartość | telemetria punktów bez łatwego zasilania i ograniczenie serwisu źródła energii |
| Kanały | pilotaż, integrator OT, partner ciepłowniczy |
| Relacje | umowa pilotażu z KPI, później SLA |
| Przychody | instalacja + abonament za punkt; alternatywnie hardware+SaaS |
| Działania | R&D, pomiary, QA, wdrożenie, aktualizacje i obsługa |
| Zasoby | IP, firmware, dane pomiarowe, montaż, system analityczny |
| Partnerzy | operator sieci, laboratorium, rzecznicy patentowi, integratorzy |
| Koszty | BOM, chłodzenie, obudowy, montaż, gateway, radio, chmura, serwis, ubezpieczenie |

TAM = (globalna liczba *kwalifikujących się punktów*) × (ARPU/rok). SAM = punkty osiągalne w wybranym segmencie i regionach. SOM = realistyczna zdolność sprzedażowo-instalacyjna w okresie planowania. Bez danych o kwalifikujących się punktach, cenach i skłonności klienta do płacenia nie podajemy pozornie precyzyjnych kwot.

**Wywiady (10–15):** obecne koszty wizyt, ważne anomalie, akceptowalny interwał, limit fałszywych alarmów, zatwierdzanie montażu, integracja SCADA, procedury bezpieczeństwa i budżet zakupów. Test rynkowy: 2 deklaracje udziału w pilotażu i jedna liczbowo wyceniona ścieżka TCO.
